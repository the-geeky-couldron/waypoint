# Waypoint promotional artwork

Original promotional compositions built from Waypoint’s native Android screenshots at a fixed London demonstration position. The screens are framed and cropped for presentation; their controls and map contents have not been fabricated.

- **Source screens:** the six map JPGs in the parent directory. They are sanitised demonstration captures, with device status and navigation bars removed.
- **Identity:** the original `waypoint-icon.png`, rendered from the Android adaptive icon.
- **Typography:** Barlow Condensed and Noto Sans from `app/src/main/res/font`, under their existing [font licenses](../../licenses/).
- **Generator:** `python3 scripts/create_readme_promo.py` from the repository root; requires Pillow.
- **Responsive art:** the README uses wide posters on desktop and portrait compositions below 640px. Individual posters are retained for reuse.
- **Privacy:** no user-provided routes, place queries, device identifiers, notification icons, home/work locations or personal screenshots belong in these assets. Use fixed public landmarks or fictional fixtures for public examples. Private QA captures remain ignored under `.tooling/`.

The artwork is not supplied by, or affiliated with, any referenced game or publisher. Game names identify inspiration only. OpenStreetMap/OpenFreeMap attribution is available inside the app through Map info and in the root README.
