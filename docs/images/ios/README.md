# iOS device screenshots

These screenshots were supplied from an iPhone running the port through LiveContainer on 5 November 2026. They show selected destinations rather than the tester's current location:

- `night-city-apple-valley.png`: Night City with Apple Valley selected.
- `night-city-destination.png`: Night City with San Francisco, Latacunga, Ecuador selected.
- `los-santos-destination.png`: Los Santos with the same Ecuador destination selected.

Each image retains its original 588 × 1280 dimensions. The time, location arrow, cellular, Wi-Fi and battery overlays were removed from two small areas at the top, with the map background filled in. Every pixel outside those areas matches the decoded original. App controls, map content and attribution are preserved. The PNG exports contain no source EXIF, GPS, timestamp or device metadata.

Only these finished images are committed and used in the root README. Raw captures remain outside the repository. The [iOS validation record](../../../ios/VALIDATION.md) separates the reported navigation result from checks that still need to run.
