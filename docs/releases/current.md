Real streets. Game worlds.

- 27 game-inspired map styles, including The Continent, Los Santos, Old West and Night City.
- Real GPS navigation for car, motorcycle and walking, with spoken directions and route recalculation.
- A native welcome screen, searchable world library and polished large-text/landscape layouts.
- **Settings → App updates** now checks GitHub Releases, downloads the latest APK and verifies its checksum and signing identity before opening Android's installer.

Download **Waypoint.apk** below (Android 8.0+). Updating an existing compatible installation keeps saved places and settings. Every world is included, with no ads or subscriptions.

This is an independent hobby project. Maps use real-world geography and original game-inspired visual styles. Online services are required; live traffic and offline routing are not included. Real-road and Android Auto head-unit validation remain outstanding.
