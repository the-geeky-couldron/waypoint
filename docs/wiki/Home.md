# Waypoint Wiki

Waypoint is a native Android navigation app that gives real streets a game-inspired map and HUD. Choose from 38 worlds, set a destination, then navigate with live GPS, spoken turns, ETA and rerouting. The worlds, saved places and quests are available without a subscription or account.

Waypoint is independent and is not affiliated with game publishers. The app uses Waypoint-authored map styles and user-interface assets with live map geography; it does not bundle game screenshots, textures or maps. Night City's place-symbol atlas includes seven Cyberpunk 2077 glyphs under the separately documented permission. Selected navigation voice recordings are bundled under separate permissions. Fonts and data carry their own notices.

## What to expect

Waypoint uses public map, search and routing endpoints. No live-traffic provider is configured. Ferrostar handles route progress, rerouting and remaining ETA from the selected routing response. These services need internet access and can be unavailable or rate-limited. Offline routing, lane guidance and guaranteed place coverage are not included. Review [[Privacy and Providers]] before relying on it for a trip.
