# Security

Use the latest stable [Waypoint release](https://github.com/the-geeky-couldron/waypoint/releases/latest). This hobby project has no guaranteed response time or long-term support commitment; fixes target the current release.

## Report privately

Please use [GitHub's private vulnerability reporting](https://github.com/the-geeky-couldron/waypoint/security/advisories/new). Include the version, affected component, expected behavior and a minimal reproduction using dummy locations and data. Do not post signing keys, tokens, real GPS traces or personal saved places.

Keep testing on your own disposable installation. Do not probe public map providers or disrupt another person's navigation. If the private form is unavailable, open an issue asking for a private contact channel without publishing exploit details.

## Scope and limits

The app's code, packaged Android components, destination import, networking, updater and release configuration are in scope. Third-party mapping services, GitHub and Android itself have their own reporting channels.

The [security review](docs/security.md) records source-level leads, implemented fixes and remaining validation. It is not a penetration-test certificate or a claim that the app is invulnerable. Real-world navigation reliability also requires road, sensor and battery testing.
